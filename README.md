# 🎮 Number Guessing Game (Python)

A simple and fun Number Guessing Game built using Python. The computer randomly selects a number between 1 and 100, and the player tries to guess it.

## 🚀 Features
- Random number generation
- User input system
- Hints: Too High or Too Low
- Counts the number of attempts
- Beginner-friendly Python project

## 🛠️ Technologies Used
- Python 3
- Random Module
- While Loop
- If-Else Statements

## ▶️ How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/Roshan-Chauhan179/Number-Guessing-Game.git
   ```

2. Open the project folder.

3. Run the Python file:
   ```bash
   python number_guessing_game.py
   ```

## 🎯 How to Play
1. Run the program.
2. Enter a number between 1 and 100.
3. Follow the hints.
4. Keep guessing until you find the correct number!

- Using conditional statements
- Generating random numbers
